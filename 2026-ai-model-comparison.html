Bedrock 與使用備註

  • Bedrock 目前涵蓋 18 家供應商：Claude 全系列、OpenAI（GPT-5.5 與 GPT-OSS 開源版）、Meta Llama、Mistral、Qwen3、DeepSeek、GLM、Kimi、MiniMax、Grok 等。
  • Claude 上架最即時——Opus 5、Sonnet 5、Fable 5 都是發布當日或同步上架，且 Opus 5 在 AWS 支援零資料保留（ZDR），對合規敏感的企業是關鍵差異。
  • GPT-5.6 家族已於 7/20 全面 GA 上架 Bedrock，上架速度明顯加快；但 Grok 4.5、DeepSeek V4 等剛發布不滿一個月的模型通常仍有數週至數月延遲，部署前請在 Bedrock console 確認實際 model ID 與區域可用性。
  • 中國模型的共同特徵：幾乎全採 MoE 架構、多數開源權重（MIT / Apache 2.0），並以極低定價競爭；Bedrock 上架的通常是前一代版本（Kimi K2.5、GLM-5、Qwen3、DeepSeek V3.2），最新旗艦（K3、V4、GLM-5.2）需走各家官方 API 或自行部署。
  • 各家跑分多出自官方發布資料，測試環境與推理檔位不同，僅供方向參考；實際選型建議以自己的工作負載驗證。
