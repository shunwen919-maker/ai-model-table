Bedrock 與使用備註

涵蓋範圍

18 家供應商

Claude 全系列、OpenAI（GPT-5.5 與 GPT-OSS 開源版）、Meta Llama、Mistral、Qwen3、DeepSeek、GLM、Kimi、MiniMax、Grok 等。

上架速度

Claude 最即時

Opus 5、Sonnet 5、Fable 5 都是發布當日或同步上架；Opus 5 在 AWS 支援零資料保留（ZDR），對合規敏感的企業是關鍵差異。

新模型

新模型上架有延遲

GPT-5.6 家族已於 7/20 全面 GA 上架，速度明顯加快；但 Grok 4.5、DeepSeek V4 等剛發布模型仍有數週至數月延遲，部署前請在 Bedrock console 確認實際 model ID 與區域可用性。

中國模型

開源、MoE、極低價

多數開源權重，以極低定價競爭；Bedrock 上架的通常是前一代版本（Kimi K2.5、GLM-5、Qwen3、DeepSeek V3.2），最新旗艦（K3、V4、GLM-5.2）需走官方 API 或自行部署。

跑分

跑分僅供方向參考

各家跑分多出自官方發布資料，測試環境與推理檔位不同；實際選型建議以自己的工作負載驗證。
